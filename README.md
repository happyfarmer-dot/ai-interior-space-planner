# 空間智繪 SpatialMind AI — 室內空間設計與裝潢物理輔助系統

具備「空間物理邏輯」與「商業落地參考價值」的 AI 室內空間設計與裝潢輔助應用程式，支援桌面與手機直立響應式操作（上方固定即時預覽畫布 + 順暢垂直捲動），並依循嚴謹的 **四步驟 13 項操作流程** 完成空間尺度校準、動線工學檢測、不可更動結構保護、光影色溫模擬、局部材質替換與台灣市場預算分析輸出。

## 四步驟 13 項操作流程

### 步驟一｜空間匯入與物理校準
1. **功能 1｜匯入室內現況照片**：支援手機直接呼叫相機拍照、從相簿／電腦上傳與拖曳圖片，並可微調實測坪數與樓高。
2. **功能 2｜空間尺度校準（Pixel-to-CM）**：內建房門 210cm / 插座 12cm / A4 / 60cm 地磚參照與畫布拉線校準、3D 透視輔助網格。
3. **功能 3｜不可更動結構與機電點位鎖定**：VLM 自動辨識與筆刷／多邊形遮罩鎖定對外窗、冷氣出風口、總配電箱、結構樑柱。

### 步驟二｜設計模式與客製需求
4. **功能 4｜現有傢俱智慧重排與空間優化**：保留現有家具，依據採光與保護遮罩生成 2～3 組最佳配置與 2D 平面圖。
5. **功能 5｜多元風格轉換與模擬圖生成**：北歐簡約、日式侘寂、現代極簡、工業風、無印原木、美式輕奢與 Before/After 滑桿對比。
6. **功能 6｜新增物件智慧擺放與合成**：自動去背、輸入真實長寬高並於畫布標示 1～3 個建議高亮擺放區進行透視合成。
7. **功能 7｜客製化裝潢需求設定**：快捷標籤與自由文字輸入，透過 LLM 解析為結構化 JSON 約束條件貫穿管線。

### 步驟三｜物理檢測與光影材質微調
8. **功能 8｜動線淨寬與人體工學自動檢測**：紅／黃／綠燈即時評估主要走道淨寬（≥75cm / <60cm 警告）、門片開啟半徑與視聽距離建議螢幕吋數。
9. **功能 9｜自然採光時段與人工照明色溫模擬**：東向晨光／西曬午後／北向柔和光／夜間模式、`3000K / 4000K / 6000K` 色溫、無主燈嵌燈與間接燈帶。
10. **功能 10｜局部材質精準替換**：點擊地板、主牆面、沙發布料、窗簾局部替換超耐磨木地板、微水泥、礦物漆、貓抓布等材質。

### 步驟四｜採購清單與預算一鍵輸出
11. **功能 11｜軟裝單品以圖搜物推薦**：框選軟裝比對 IKEA、MUJI 無印良品、NITORI 宜得利、MR. LIVING 居家先生實體商品規格與售價。
12. **功能 12｜粗估工程與軟裝 BOM 預算表**：差異計算坪數／件數、台灣行情低高標區間、預算上限檢核與強制免責聲明。
13. **功能 13｜預算分析表一鍵輸出**：
    - 一鍵下載含 **UTF-8 BOM** 之 Excel / CSV 報表（含品項、數量／坪數、單價、小計與總預算佔比）。
    - 一鍵生成 A4 排版完整設計與預算企劃書並直接呼叫瀏覽器列印／另存 PDF。
    - 一鍵複製條列式純文字預算明細至系統剪貼簿，方便貼至 LINE 討論。

## 系統目錄結構

```text
ai-interior-space-planner/
├── .env.example                     # VLM / Diffusion / LLM API 端點與金鑰環境變數範本
├── .github/workflows/deploy.yml     # GitHub Pages 自動化部署流程
├── public/samples/                  # 功能 6 單品擴充去背素材
└── src/
    ├── types/design.ts              # 空間設計物理與商業 BOM 型別契約
    ├── data/                        # 風格庫、建材庫、台灣家居規格資料庫
    ├── services/                    # AI Pipeline 服務抽象層 (Hybrid Mock + Live API)
    ├── store/                       # Undo / Redo 狀態管理與版本快照 (Version History)
    ├── utils/                       # 幾何碰撞、人體工學、BOM 計算與報表匯出工具
    └── components/                  # 畫布視口、2D 平面圖、四步驟面板與 A4 企劃報表
```

## 本地開發與 API 整合

```bash
npm install
npm run dev
```

若需串接真實外部付費 API（OpenAI Vision / Replicate ControlNet Inpainting / LLM），請複製 `.env.example` 為 `.env.local` 並設定 `VITE_AI_MODE=live` 與對應金鑰。
